# Data directory

`sample_monthly_market_data.csv` contains 84 monthly synthetic observations (January 2019–December 2025) for an illustrative apparel/textile demand index, export value index, and cotton input-cost index. The values are generated for demonstration and are not measured market data. They must not be cited as real Indian industry statistics.

For a final evidence-based submission, replace the sample with a public, traceable dataset. Recommended sources are listed in the root README and report.
